# Artesanías de Mármol Santa Mónica

## Descripción del proyecto

Artesanías de Mármol Santa Mónica es un sitio web desarrollado para mostrar los productos y trabajos elaborados en mármol y granito. Su objetivo es ofrecer a los clientes un catálogo digital donde puedan consultar los diferentes productos, visualizar imágenes y comunicarse con el negocio para solicitar cotizaciones.

El sitio cuenta con un diseño adaptable a dispositivos móviles y computadoras.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos y adaptación a diferentes dispositivos.
- **JavaScript:** funcionalidades, interacciones y elementos dinámicos.
- **Git y GitHub:** control de versiones y almacenamiento del código.
- **Visual Studio Code:** editor de código recomendado.

## Requisitos previos

Para descargar y ejecutar el proyecto se necesita:

- Una computadora con Windows, Linux o macOS.
- Navegador web actualizado (Google Chrome, Firefox o Edge).
- Git instalado.
- Visual Studio Code (recomendado).
- Extensión Live Server de Visual Studio Code para ejecutar el sitio localmente.

## Cómo descargar el proyecto

1. Abrir el repositorio del proyecto en GitHub.
2. Copiar la dirección HTTPS del repositorio.
3. Abrir una terminal en la computadora.
4. Ejecutar el siguiente comando:

```bash
git clone URL_DEL_REPOSITORIO
```

5. Entrar a la carpeta descargada:

```bash
cd NOMBRE_DEL_REPOSITORIO
```

También es posible descargar el proyecto desde GitHub mediante la opción **Code > Download ZIP**.

## Configuración del proyecto

1. Abrir Visual Studio Code.
2. Seleccionar la opción **File > Open Folder**.
3. Buscar y abrir la carpeta del proyecto.
4. Verificar que los archivos principales estén presentes:

- `index.html`
- `styles.css`
- `script.js`
- Carpeta `img` con las imágenes del catálogo.

No es necesario instalar paquetes adicionales ni configurar un servidor de base de datos para ejecutar la versión estática del sitio.

## Cómo ejecutar el proyecto

Para visualizar el sitio web localmente:

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Instalar la extensión **Live Server**, si todavía no está instalada.
3. Abrir el archivo `index.html`.
4. Dar clic derecho sobre el archivo.
5. Seleccionar **Open with Live Server**.

El sitio se abrirá automáticamente en el navegador predeterminado.
